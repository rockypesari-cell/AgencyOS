# ADR-001

## Title

Documentation Standard

---

## Status

Accepted

---

## Date

2026-07-31

---

## Context

AgencyOS is a long-term enterprise project.

As the project grows, architecture decisions, progress, roadmap, and research must remain synchronized.

Without documentation standards, project knowledge becomes fragmented and previous work is forgotten.

---

## Decision

AgencyOS adopts a documentation-first workflow.

Project documentation is organized as follows:

PROJECT_STATUS.md
Current project status.

PROJECT_MEMORY.md
Historical milestones and important events.

ARCHITECTURE.md
System architecture.

ROADMAP.md
Future features and priorities.

research/
Research notes about external projects.

ADR/
Architecture Decision Records.

sprints/
Sprint planning and outcomes.

---

## Consequences

Positive

- Clear project history
- Easier onboarding
- Better architecture consistency
- Less duplicated work
- Better AI collaboration

Negative

- Requires documentation updates with major changes.
